## 👨‍💻 About This Project

This repository contains the source code for my personal portfolio website, built from scratch with the latest modern web technologies. It serves as a central hub to showcase my professional path, technical skills, and selected real-world projects.

The site is engineered for **high performance**, **seamless bilingual UX** (Indonesian & English), and **ATS-optimized print layouts** — so that recruiters can download a perfectly formatted CV directly from the site, or request a Word (`.docx`) export.

---

## ✨ Key Features

| Feature | Details |
|---|---|
| 🌐 **Bilingual (i18n)** | Instant toggle between Indonesian (ID) and English (EN) via client-side state — no page reload |
| 🌙 **Dark / Light Mode** | Full theme toggle using CSS variables and `useSyncExternalStore` backed by `localStorage` |
| ⚡ **Performance First** | Lighthouse 90+ via static generation, Turbopack dev server, and optimized component tree |
| 📱 **Fully Responsive** | Adaptive layouts from 320px mobile to ultra-wide monitors |
| 🎨 **Premium UI & Animations** | CursorGlow, PageLoader, Shader background animations (GLSL via `@paper-design/shaders-react`), TiltCard, SpotlightCard, MagneticButton, VerticalCutReveal, TracingBeam |
| 🔍 **SEO + JSON-LD** | Full `<meta>`, Open Graph, Twitter Card, and Schema.org `Person` structured data |
| 🎓 **Certifications Section** | Displays professional certifications with credential links and images |
| 💬 **Testimonials Section** | Social proof section from peers and supervisors |

## 🚀 Getting Started (Local Development)

```bash
# 1. Clone the repository
git clone https://github.com/ferdiansyach/ferdiansyach-portfolio.git
cd ferdiansyach-portfolio

# 2. Install dependencies
npm install

# 3. Run the development server (Turbopack)
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

### Available Scripts

```bash
npm run dev        # Dev server with Turbopack
npm run build      # Production build
npm run lint       # ESLint (next/core-web-vitals + TypeScript)
npm run test       # Vitest (watch mode)
npm run test:run   # Vitest single run
```
