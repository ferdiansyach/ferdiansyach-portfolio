# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Recruiters and clients evaluating Ferdiansyach's work, skills, and credibility.

## Product Purpose

A personal portfolio website that presents real projects, technical skills, CV / PDF materials, certifications, and contact paths so visitors can quickly assess fit.

## Positioning

A portfolio that highlights the full range of the author's technical skills, not just one specialty.

## Operating Context

Visitors browse the home page, project highlights, individual project pages, and PDF portfolio/resume pages. The site serves both Indonesian and English content.

## Capabilities and Constraints

- Showcase fullstack, data, AI, and supporting engineering work through real project case studies.
- Provide downloadable / viewable PDF portfolio and resume materials.
- Keep project claims factual; do not invent clients, metrics, or experience.
- Preserve bilingual content and the current portfolio structure unless the user asks for a change.
- Existing codebase already defines the web stack and route structure.

## Brand Commitments

- Name: Ferdiansyach.
- Voice: technical, credible, achievement-oriented.
- Commitments: use real work, real screenshots, real links, and real PDF assets.

## Evidence on Hand

- `src/app/page.tsx` wires the home page sections.
- `src/components/sections/HeroSection.tsx` links to `/portfolio-pdf` and `/projects-pdf`.
- `src/data/projects.ts` contains the project catalog and supporting copy.
- `src/components/sections/CertificationsSection.tsx` and the project pages indicate certifications and case-study coverage are part of the site.

## Product Principles

- Lead with proof.
- Show breadth without hiding depth.
- Keep every claim grounded in real artifacts.
- Make recruiter/client paths to evidence obvious.
- Preserve bilingual clarity.
